# 孤岛浪花 · island-wave-cards

> 每个人都是一座孤岛。把想说的话写成卡片，它会变成一朵浪花，漂进某一片海，
> 被某一个人看到一次，然后永远退去。

一个供人倾诉与记录的**匿名卡片网站**：没有关注、点赞、评论、搜索，没有推荐算法，
只有实时刷新里的偶遇。你点开一张卡片看完它，它就从你的海面永远消失——
你不知道它来自哪座岛，它也不会再来。只有你自己，能回到自己的岛看往日写下的字。

## 视觉：夜航信号

整个界面是一台**夜间的海面观测站**：

- **人说的话用衬线字**（宋体系，系统自带，零加载成本），**系统记的账用等宽字**
  （IBM Plex Mono）——一眼能分清哪句是卡片、哪句是读数。
- **配色只有六支**：船体黑（海）、舱室灰（卡片）、骨架线、浪沫白（正文）、
  刻度灰（次要信息）、**信号琥珀（唯一强调色，只标"此刻"）**，外加一个活体绿标"未读"。
- **左侧是仪表台**：潮位曲线、可见条数、今日已读、我的记录、信标状态；
  右侧是信流，每条卡片带 `NO.` 编号、精确到分钟的靠岸时刻、一条代表分类的潮色脊。
- **卡片读走时不是简单淡出**，而是"信号衰减"——模糊、失色、横移、消散，
  像浮标的讯号在噪声里沉下去。

## 背景是一片活海

主界面的背景不是贴上去的装饰动画，**它就是主界面所在的那片海**——
由 `frontend/sea.js` 用 Canvas 实时绘制，形态取自海图（bathymetric chart）的语言：
等深线、每第 4 根加粗的计曲线、浮沫、以及每隔十几秒扫过海面的信号灯。

关键在于**它和左栏仪表读的是同一份数据**（`frontend/tide.js` 是全站唯一的潮汐真源）：

| 潮汐数据 | 背景海面的表现 |
| --- | --- |
| 当前潮位 | 浪有多高、浮沫有多少 |
| 潮势（涨/落 cm/h） | 水流往哪边走、走多快；平潮时海面几乎静止 |
| 本次落差 | 与浪高共同决定涌浪的规模 |

潮汐模型按真实半日潮推算（`M2 / S2 / N2 / K1 / O1` 五个分潮谐波叠加），
相位锚定在固定历元上，所以**潮位跟着世界时钟涨落**，同一时刻所有人看到的是同一片海。

还有一处联动：**卡片被读走、退场的那一刻，它在海图上会留下一圈荡开的涟漪**——
"看过即消失"这件事，在背景上是真的看得见的。

无障碍：`prefers-reduced-motion` 下自动降级为静态一帧；页面切到后台时暂停渲染。

## 快速开始

**方式一：直接双击打开 `frontend/demo.html`** — 纯前端演示版，数据存在浏览器 localStorage 里，无需任何服务器或云端配置。

方式二：启动本地服务器——

```bash
cd backend
npm start          # 默认 http://localhost:3000，可用 PORT=8080 覆盖
```

> 注：`frontend/config.js` 已填入「孤岛浪花」应用（2026-11-03 激活）的真实云服务配置，线上真实版开箱即用；`demo.html` 仍可零门槛试玩。

## 测试

改动前端后可以跑一遍集成冒烟测试，它会用 jsdom 真实驱动 demo 版走完整流程
（登岛 → 卡片海 → 写卡 → 打开卡片 → 浪花退去 → 我的孤岛 → 离岛），
并断言渲染结构、交互联动，以及**背景海面引擎**（等深线是否生成、
海面潮位是否与仪表同源、水流是否真的在动、流向是否与潮势一致、
卡片退场是否激起涟漪）：

```bash
npm install jsdom          # 唯一依赖
node test/smoke.js
```

## 架构说明

- **前端是纯静态站点**（HTML/CSS/JS，无框架、无构建步骤），通过 CDN 引入
  WorkBuddy Cloud SDK，直连托管云服务。
- **真实后端是托管云服务**（Database + Auth），不在本仓库内：
  - `cards` 表：每条文字一朵浪；`card_seen` 表：某位读者已看过的卡片。
  - **「看过即消失」由数据库 RLS 策略在服务端强制执行**——`cards` 的读取策略嵌有
    `NOT EXISTS` 子查询，你看过的卡连查询结果都进不来，不是前端藏起来。
  - `card_seen` 仅本人可读写（隐私：无人能查谁看过什么）；未登录用户完全锁死。
  - `owner_id` 由数据库 `DEFAULT auth.uid()` 写入，客户端绝不发送。
- **登录**：手机号验证码（默认）+ 微信登录。
- `frontend/local-backend.js` 是一个可选的本地演示后端：用 localStorage 模拟同一套
  API（含服务端「看过即消失」过滤与其他岛漂卡的模拟器），让没有云端时也能完整体验。
  线上版不引用它。

## 安全说明

- `.env` 系列文件、`*.db` / `*.sqlite3` 数据库文件已被 `.gitignore` 强制拦截，
  **严禁**绕过过滤提交。
- `frontend/config.js` 中的 `publishableKey` 是**公开标识**：本身不带任何权限，
  服务端还会校验 Origin，可安全出现在前端代码中（线上页面源码里本来就有）。
  它不是密钥，但也请注意：要部署自己的实例，请替换为你自己应用的配置。
